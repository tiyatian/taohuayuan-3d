# 桃花源 · 一程山水

以《桃花源记》为意境的可漫游三维场景，包含桃林、溪流、山谷、江南村舍、石桥、木舟与田地。所有场景几何和材质均在浏览器中生成，Three.js 已随项目保存在本地，无外部模型或音频加载依赖。

## 本地打开

在本目录执行：

```sh
python3 -m http.server 8769 --bind 127.0.0.1
```

访问 http://127.0.0.1:8769 。请通过 HTTP 服务运行，不要直接双击 HTML。

## 操作

- 鼠标拖动环顾，滚轮调整观景距离；触屏支持滑动和双指缩放。
- 点击「入境漫游」后，用 W A S D 或方向键移动，Shift 快行，Esc 结束漫游。触屏显示虚拟摇杆。
- 点击下方地点、场景热点或舆图切换游览位置。
- 右下角切换清晨、午后、暮色，右上角开启合成溪流与鸟鸣环境音、全屏和操作指南。
- 河流与房舍设有通行边界；石桥可以步行穿越。

## 文件

`index.html` 与 `style.css` 为界面，`main.js` 管理渲染、水面倒影和交互；`terrain.js`、`nature.js`、`village.js` 分别为地形、植被、村落；`world-utils.js` 提供确定性地形和纹理工具。

## GitHub Pages

此目录是可直接发布的完整站点，`index.html` 位于仓库根目录。

1. 在 GitHub 创建空仓库，将本目录所有文件上传，保留 `vendor/` 子目录结构。
2. 在仓库 Settings → Pages 中选择 Deploy from a branch。
3. 选择 `main` 分支、`/(root)` 目录并保存。
4. 等待 Pages 的部署状态成功，再打开设置页显示的访问链接。

后续推送到 `main` 的修改会自动触发 Pages 更新。
